# Contributing to Gemini API CLI

Thank you for your interest in `gemini-api`!

## Pull Requests Are Not Accepted

At this time, we are **not accepting external pull requests or code
contributions** to this repository. Any pull requests opened here will be
closed without review.

## Bugs and Feedback

We welcome **bug reports and feedback** via
[GitHub Issues](https://github.com/google-gemini/gemini-api-cli/issues).

When reporting a bug, please include:

- **CLI version:** Output of `gemini-api version`
- **Environment:** Operating system and architecture (for example, macOS arm64,
  Linux amd64, Windows amd64)
- **Steps to reproduce:** Exact command and flags run (use `--dry-run` to
  preview requests safely — **never** include your `GEMINI_API_KEY` or
  credentials)
- **Expected vs. actual behavior:** Full error output, exit code, or unexpected
  response
